# Personal Project with C++ and Raylib

## Overview
This is a personal project developed using **C++** and the **Raylib** library. The goal is to explore creative programming techniques and graphics rendering while building a fun and engaging application.

## Game Description
This project is a **roguelike video game** where the player must explore the environment to find a **variable number of keys** required to open a **chest**. The challenge lies in navigating the game world, avoiding obstacles, and strategically collecting keys while adapting to procedural gameplay elements.

## Features
- Developed entirely in **C++**
- Utilizes **Raylib** for graphics and rendering
- Designed and implemented by **Catalin Stanciu**
